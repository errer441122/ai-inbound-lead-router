    When something goes wrong
    
    
    
      
    A personal email arrivesgmail.com, libero.it, outlook.com, proton.me...
    The corporate-email check stops it before the website fetch and the AI call. The contact is still saved, for self-serve nurture.
    
      
    The website blocks the fetchHTTP 403 or 8-second timeout
    The request continues on error, so the lead is not lost. Without page text the prompt asks for a score under 75, and the lead goes to human review.
    
      
    The AI call failsrate limit or outage at the model provider
    This node also continues on error. The score reads as 0, so the lead lands in the review list instead of being routed on a guess.
    
      
    HubSpot or Slack returns an errorfor example 429, too many requests
    The run fails and the Error Trigger posts the failed node and the error to #martech-alerts. Ops replays the run from n8n's execution history.
    
      
    The AI writes an opener for Salesai_personalized_hook
    It is posted in Slack for a rep to check and saved on the contact. Nothing is emailed to the lead automatically.
