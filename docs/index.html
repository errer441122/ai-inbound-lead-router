automated lead sorting · n8n + HubSpot + AI

Sort incoming website leads automatically and send only qualified ones to Sales.

Every time someone fills out your contact form, this system checks if Sales already knows them, filters personal Gmail spam, scores company fit with AI, and updates HubSpot without overwriting existing rep or campaign data.

    What happens when something goes wrong
    
    
    
      
    A personal email arrivesgmail.com, libero.it, outlook.com, proton.me...
    The corporate-email check stops it before website lookup and AI scoring. The contact is still saved cleanly for self-serve nurture at €0 AI cost.
    
      
    The company website blocks accessHTTP 403 or 8-second timeout
    The workflow continues on error so the lead is never lost. Without page text the Code node ignores the AI's answer and the lead goes to human review.
    
      
    The AI is sure, but the message asks for nothingconfidence 95 and 98 out of 100
    It happened twice in 30 test cases: a newsletter sign-up and a general question would have reached Sales. Now the AI must copy the words that ask for work; if they are not in the message, a person decides. What the test showed.
    
      
    The AI provider fails or times outrate limit or temporary outage
    The Code parser catches the error safely and defaults confidence to 0, routing the lead to manual review instead of guessing.
    
      
    HubSpot or Slack returns an errorfor example 429, too many requests
    The standalone Error Workflow posts the failed step and error message to #martech-alerts so Ops can replay the run from n8n history.
    
      
    The AI writes a suggested email openerai_personalized_hook
    It appears only in Slack for a human rep to check and is saved on the HubSpot contact. Nothing is ever emailed to the prospect automatically.
