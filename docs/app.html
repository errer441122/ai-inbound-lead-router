Your orders export in, your retention report out.

RFM segments, lifecycle stages, repeat purchases, time to second order and value by market for your own customers, plus the customer list your CRM team works from. Everything runs in this page: your file never leaves your computer.

Loading the analysis engine (about 10 seconds the first time)

Build the report

Use the Shopify orders export as it comes (Orders > Export), or any CSV with one row per order and the columns email (or customer_id), order_date, order_value and, optionally, country. Files saved again by Excel are fine: semicolons, decimal commas, dates as 20/05/2026.

The page runs the repository's own Python code in your browser with Pyodide: the same functions and tests as src/store_report.py, which reproduces every published number on the public data. The small example is handwritten with example.com addresses; the UCI file is real public data (CC BY 4.0).
